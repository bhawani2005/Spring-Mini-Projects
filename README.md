## 🚀 How to Clone This Repository

Run the following command in Git Bash:

```bash
git clone https://github.com/bhawani2005/Spring-Mini-Projects.git
```

After cloning:

1. Open Eclipse IDE.
2. Select **File → Import**.
3. Choose **Existing Maven Projects** where applicable.
4. Browse to the cloned repository.
5. Select the project you want to import.
6. Click **Finish**.
7. Configure the database if required by the project.
8. Run the application.
